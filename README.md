# 明石布 スマホコントローラー README (by google ai studio)

ロボット制御用 Web コントローラーおよび、カメラ画像認識（OpenCV / YOLO-World）による雑巾のよれ・歪み検知システムのプログラムです。

マイコンとのシリアル通信、CAN バスモニター、Yaw角コンパス、4輪電流監視、試合用タイマー、そして OpenCV による雑巾の状態検知とスマホ振動を統合しています。

## 2. システムアーキテクチャ & 通信プロトコル

```
 [ マイコン (Arduino / ESP32 / STM32) ]
          ▲ 1文字コマンド ('R','T','E','S')
          ▼ テレメトリ文字列 ("DATA,...", "CAN,...")
    [ USB シリアル (115200 bps) ]
          ▼
   ┌─────────────────────────────────────────────────────────┐
   │ server.py (FastAPI / WebSocket サーバー)                 │
   │  - シリアル送受信スレッド (serial_lock最小化)               │
   │  - 10Hz 一括ブロードキャスト (JSON 1回シリアライズ)          │
   │  - /api/cloth_alert エンドポイント                        │
   └──────▲──────────────────────────────────▲───────────────┘
          │ POST /api/cloth_alert            │ WebSocket /ws
          │ (常駐キューワーカー)             │ (10Hz JSONテレメトリ)
   ┌──────┴──────────────┐           ┌───────┴───────────────┐
   │ cloth_detector.py   │           │ robot_index.html      │
   │  - USBカメラ 720x480 │           │  - Yaw 角コンパス      │
   │  - 輪郭探索 1回集約   │           │  - 4輪ステア電流バー     │
   │  - 凸性・矩形度解析    │           │  - CAN モニター        │
   │  - ヘッドレス安全化    │           │  - スマホ振動 & 音     │
   └─────────────────────┘           │  - 試合進行タイマー     │
                                     └───────────────────────┘
```

### 2.1 シリアル通信仕様 (マイコン ⇔ server.py)

- **ボーレート**: `115200 bps` (デフォルト)
- **データフォーマット**: 改行（`\n`）区切りテキスト

#### ① ロボットテレメトリ (`DATA` ヘッダー)
```
DATA,<yaw_mrad>,<con_alive>,<roller_mode>,<steer_fl>,<steer_fr>,<steer_rl>,<steer_rr>\n   <-こうやってprintfしてねってことです
```
| フィールド | 型 | 単位 / 範囲 | 内容・例 |
| :--- | :--- | :--- | :--- |
| `yaw_mrad` | 整数 | ミリラジアン | `1570` (= 約 1.57 rad = 90°) |
| `con_alive` | `0` or `1` | フラグ | `1` = コントローラー接続中, `0` = 切断 |
| `roller_mode` | `0` or `1` | フラグ | `1` = ローラー回転中, `0` = 停止 |
| `steer_fl` | 整数 | mA (0〜2500) | 左前ステアモーター電流 (例: `320`) |
| `steer_fr` | 整数 | mA (0〜2500) | 右前ステアモーター電流 (例: `280`) |
| `steer_rl` | 整数 | mA (0〜2500) | 左後ステアモーター電流 (例: `210`) |
| `steer_rr` | 整数 | mA (0〜2500) | 右後ステアモーター電流 (例: `290`) |

#### ② CAN パケット情報 (`CAN` ヘッダー)
```
CAN,<can_id_hex>,<byte0>,<byte1>,<byte2>,...\n
例: CAN,101,0A,12,FF,00\n
```

#### ③ 操作コマンド (Web → マイコン)
| コマンド文字 | 機能名称 | 動作 |
| :---: | :--- | :--- |
| **`'R'`** | **RESET YAW** | ジャイロ / オドメトリの Yaw 角を 0° にリセット |
| **`'T'`** | **ROLLER TOGGLE** | ローラーの正転 / 停止をトグル切り替え |
| **`'E'`** | **USER SLOT** | 予備スロット |
| **`'S'`** | **EMERGENCY STOP** | **非常停止** |

## 3. 布よれ・歪み検知アルゴリズムの仕組み

`cloth_detector.py` は、雑巾（標準サイズ: 長辺 300mm × 短辺 200mm, アスペクト比 1.50）の形状特徴を数学的に高速解析します。

### 判定パラメータと閾値
1. **凸性 (Convexity / `BOMP_SCORE = 0.85`)**
   - 輪郭面積 ÷ 凸包面積 (Convex Hull Area)
   - 布が途中で折れ曲がったり、シワで内側に窪んでいると値が低下（< 0.85 で **`折れ・凹み`** 警告）。
2. **矩形度 (Rectangularity / `SHAPE_SCORE = 0.85`)**
   - 輪郭面積 ÷ 最小外接回転矩形面積 (Min Area Rect Area)
   - 布が長方形から崩れて菱形や台形、歪な形になると低下（< 0.85 で **`長方形の崩れ`** 警告）。
3. **コーナー数 (`TARGET_CORNERS = 4`)**
   - Douglas-Peucker アルゴリズム（`cv2.approxPolyDP`）による多角形近似頂点数。
   - 角がめくれたり重なって頂点数が 4 以外になった場合に **`角のめくれ`** 警告。
4. **縦横比 (Aspect Ratio / `REAL_ASPECT = 1.50`)**
   - 最小外接矩形の（長辺 ÷ 短辺）。
   - 許容誤差 ±0.35（範囲: 1.15 〜 1.85）を逸脱した場合に **`縦横比の歪み`** 警告。

## 4. 動作要件・セットアップ手順

### 4.1 動作環境
- **OS**: Linux (Ubuntu 20.04/22.04, Raspberry Pi OS 64-bit 推奨), macOS, Windows
- **Python**: 3.9 以上
- **ハードウェア**:
  - USB Web カメラ (720x480 解像度対応)
  - USB-UART シリアル変換アダプタ (またはマイコン直結 USB)
  - 操作端末: スマートフォン (Android Chrome 推奨), タブレット, ノート PC

### 4.2 依存ライブラリのインストール

```bash
# 基本ライブラリ
pip install fastapi uvicorn[standard] pyserial opencv-python numpy

# YOLO-World物体検出を使用する場合
pip install ultralytics
```


### 4.3 Linux でのポート・デバイス権限設定

シリアルポート（`/dev/ttyACM0` や `/dev/ttyUSB0`）およびカメラ（`/dev/video0`）へのアクセス権をユーザーに付与します:

```bash
sudo usermod -a -G dialout $USER
sudo usermod -a -G video $USER
# 反映のため再ログイン、または一時的にパーミッション解放:
sudo chmod 666 /dev/ttyACM* /dev/ttyUSB* /dev/video* 2>/dev/null || true
```

## 5. クイックスタートガイド

### ステップ 1: サーバー (`server.py`) の起動

ロボットと PC / SBC を USB ケーブルで接続し、サーバーを起動します。

```bash
python3 server.py
```
- 起動に成功すると `[Serial] Connected successfully!` と表示され、ポート `8000` で待受が始まります。
- **シリアルポート変更時の起動例**:
  ```bash
  SERIAL_PORT=/dev/ttyUSB0 BAUD_RATE=115200 python3 server.py
  ```

### ステップ 2: コントローラー画面をブラウザで開く

ロボットと同じローカルネットワーク（Wi-Fi 等）に接続したスマートフォンや PC のブラウザから以下を開きます:
```
http://<サーバーのローカルIPアドレス>:8000
```
- 画面右上のステータスが **`ONLINE`**（緑）になれば接続完了です。
- **スマートフォン利用時の推奨**:
  - 画面上部の **`[ ⛶ ]`** ボタンで全画面表示に切り替えられます。
  - 画面を一度タップすることで、Web Audio による警告ビープ音と Web Vibration API による触覚振動が有効になります。

### ステップ 3: 布よれ検知 (`cloth_detector.py`) の起動

別のターミナルを開き、カメラ認識スクリプトを実行します。

```bash
python3 cloth_detector.py
```
- **オプション指定例**:
  ```bash
  # カメラ番号を指定する場合 (デフォルト: 0)
  CAMERA_ID=1 python3 cloth_detector.py

  # ディスプレイがないロボットSBC / SSH接続時 (ヘッドレスモード)
  HEADLESS=1 python3 cloth_detector.py
  ```
- **GUI 操作キー**:
  - `d` / `D`: 布よれ検知機能の ON / OFF 切替
  - `q`: 終了

## 6. Web コントローラー操作方法 & 機能解説

### 6.1 画面レイアウト
- **上部バー**: 接続ステータス（ONLINE / RECONNECTING / OFFLINE）、歪み検知状態、振動強度切替（最大 / 標準）、最適化コード確認モーダル
- **試合タイマー**: `START` / `STOP`、`RESET`。0:30, 1:00, 1:30, 2:30, 3:00 に自動通知
- **Yaw 角姿勢 & コンパス**: ロボットの現在進行方向をリアルタイム表示。**タップで 0° リセット**
- **ハードウェアステータス**: `CON`（通信基板）、`ROLR`（ローラー回転）、4輪電流バー（mA）
- **CAN バスモニター**: 受信した CAN ID と最新データバイト列をリアルタイム更新
- **アクションパッド**: 大きなボタンで確実なタッチ操作（キーボードショートカット対応）

### 6.2 キーボードショートカット一覧
| キー | アクション | 説明 |
| :---: | :--- | :--- |
| **`Space`** | **タイマー開始 / 停止** | 試合タイマーの START / STOP をトグル |
| **`R`** | **Yaw リセット** | Yaw 角を 0.0° にリセット |
| **`T`** | **ローラー切替** | ローラーの正転 / 停止をトグル |
| **`E`** | **ユーザースロット** | 予備機能スロット実行 |
| **`S`** | **非常停止 (EMERGENCY STOP)** | 全動作即時停止 |

### 6.3 布よれ検知アラート表示
布によれや歪みが発生すると、コントローラー画面に赤色の警告バナーが点滅表示され、以下が同時に実行されます:
1. **触覚フィードバック**: スマホ本体が `[1400ms 振動, 45ms 停止, 1400ms 振動]` の強振動パターンを実行
2. **警告音**: 1320Hz + 880Hz の電子警告音（ビープ）が鳴動
3. **要因詳細表示**: 「要因: 折れ・凹み / 角のめくれ」や「凸性スコア: 0.74」がリアルタイム表示

## 6. トラブルシューティング

| 現象 | 想定される原因 | 対処方法 |
| :--- | :--- | :--- |
| **`[Serial] Disconnected... Reconnecting` が繰り返される** | ポート名が一致していない、またはパーミッション不足 | 1. `ls /dev/tty*` で正しいポートを確認（例: `/dev/ttyUSB0`）。<br>2. `SERIAL_PORT=/dev/ttyUSB0 python3 server.py` でポート名を指定して起動。<br>3. `sudo chmod 666 /dev/ttyUSB0` を実行。 |
| **カメラが開かない (`Cannot open camera`)** | カメラデバイス番号の不一致、または他のプロセスがカメラを占有 | 1. `ls /dev/video*` を確認。<br>2. `CAMERA_ID=1 python3 cloth_detector.py` のように番号を変更。<br>3. 他のカメラアプリを終了。 |
| **スマートフォンが振動しない** | iOS (Safari) の仕様制限、またはブラウザのユーザーインタラクション制限 | 1. **iOS (iPhone/iPad) の Safari は Apple の仕様により Web Vibration API に非対応です**。触覚振動機能を利用する場合は **Android 端末（Google Chrome）** をご使用ください（iOS でも警告音と画面点滅は動作します）。<br>2. ブラウザのセキュリティ仕様上、一度画面内をタップして音声・振動の権限をアクティブにしてください。 |
| **SSH 接続時に `cloth_detector.py` がクラッシュする** | X11 ディスプレイ環境がない状態で `cv2.imshow` が呼ばれた | `HEADLESS=1 python3 cloth_detector.py` でヘッドレスモード起動してください。ウィンドウ描画がスキップされ安全に稼働します。 |
| **CAN データがモニターに表示されない** | マイコン側から `CAN` ヘッダー形式で送信されていない | マイコンのシリアル送信出力が `CAN,101,00,11,22\n` のフォーマットに合致しているか、ボーレートが 115200 bps かを確認してください。 |
